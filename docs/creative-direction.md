# Creative direction

## Concept

**Intelligence in Motion** presents Jabir Khan as an engineer working across intelligence, product, and infrastructure. The visual language pairs scientific precision with editorial scale: technical labels provide structure, serif phrases create human contrast, and a restrained luminous system indicates active computation.

## Visual thesis

The site should feel like an evolving technical exhibit, not a product landing page. Content is arranged as chapters on a precise twelve-column field. Large typography establishes hierarchy while linework, registration marks, and a static Cognitive Engine diagram suggest an underlying system.

## Palette

- Primary background: `#050506`
- Secondary background: `#0a0a0c`
- Surface: `#101014`
- Primary text: `#f2f1ec`
- Secondary text: `#9b9b9f`
- Subtle border: `rgba(255, 255, 255, 0.12)`
- Global signal: phosphor `#b8ff63`

Only one project accent is dominant within a project chapter:

- Dev Pulse AI: warm signal `#ff8a5c`
- RontgenAI: electric cyan `#5de4ff`
- CognoraAI: phosphor `#b8ff63`
- OrkestriaAI: signal violet `#8974ff`

## Typography

- Manrope: primary display and body
- Instrument Serif: editorial counterpoint
- IBM Plex Mono: labels, indexes, status, and technical metadata

Display text uses tight line-height and responsive `clamp()` sizing. Serif is reserved for meaningful phrases, never used as decoration. Mono labels are small but maintain accessible contrast.

## Composition

- Desktop: 12 columns with wide outer margins.
- Tablet: 8 columns with reduced asymmetry.
- Mobile: 4 columns with intentionally reordered compositions.
- Project chapters alternate text alignment while retaining a stable reading order.
- Sections use generous vertical space without relying on empty “luxury” spacing.

## Static Cognitive Engine

Phase 1 uses a CSS-rendered technical silhouette: concentric gyroscopic tracks, an offset translucent core, connection nodes, and fine registration lines. It is an art-directed fallback and visual contract—not a substitute for Phase 3 WebGL.

## Texture and atmosphere

The background combines a low-contrast technical grid, radial light fields, and a fixed grain layer. Texture never sits directly at high opacity over body text. Borders remain sharp; project surfaces use restrained radii.

## Explicit exclusions

- No glassmorphism card grid
- No purple gradient hero
- No generic floating spheres
- No neon cyberpunk city language
- No aggressive perspective card tilting
- No copied Cosmos Studio layout or assets
- No invented project outcomes
